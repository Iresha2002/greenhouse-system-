SmartGrow OS — Project Summary

Stack: React + Vite + Tailwind CSS v4 (frontend), Node.js + Express + MongoDB/Mongoose (backend), JWT authentication
Repository: github.com/Iresha2002/greenhouse-system- (branch main)

The 4 Modules

#ModuleWhat it does
1Smart GreenhouseLive sensor monitoring, climate zones and actuator control (already existed).
2Crop MarketplaceFarmers sell fresh harvests. Customers get a cart, checkout and order history; farmers have a fulfilment portal (already existed).
3Agricultural Suppliers MarketplaceBuilt in an earlier session (11 stages).
4ExpertConnectReplaced the old Hydroponic Bay. Built in 12 stages.

Suppliers Marketplace (Stages 1–11)

  • Catalog: 10 product categories; search by chemical formula (NPK, EC, pH) or protocol (RS485, LoRaWAN).
  • Customer side: server-verified basket, checkout (cash on delivery or warehouse pickup), order tracking and cancellation with stock restored, profile page.
  • Supplier portal: 8 KPI cards, product editor, inline stock controls, order workflow (Pending to Delivered).
  • Rankings: best sellers computed from real orders, with no fake ratings.

ExpertConnect (Stages 1–12)

StageWhat was built
1–2Landing page; navigation renamed from Hydroponic Bay.
3expert role, ExpertProfile model, directory with search and filters, profile cards and modal, 4 seeded experts.
4Expert application form and admin approve/reject. Nobody can verify themselves.
5–6Problem reports with up to 5 photos (max 2 MB each) and rule-based expert matching that explains each suggestion.
7Booking with live slots (Sri Lanka time), expert availability editor, double-booking blocked (409).
8Private chat per consultation, with photos and highlighted diagnostic notes.
9Structured expert recommendation (observations, causes, actions, safety, follow-up) with an advice disclaimer.
10In-app notifications; 1–5 star reviews only after a completed consultation, updating the expert's rating.
11Admin moderation tab: analytics, all consultations, review removal, account suspension.
12Full 8-workflow test run and README documentation.

Security Built In

  • Role-based access for farmer, expert, supplier, customer and admin.
  • Farmers cannot see each other's consultations; experts can only act on their own.
  • Suspended accounts are blocked at login and on every request.
  • Image uploads validated for type and size.
